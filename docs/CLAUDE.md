# Инструкции для ИИ-агента

Проект: MVP «Умный кредитный кабинет предпринимателя» для хакатона Альфа-Банка. Цифровой кредитный конвейер для малого и микробизнеса: клиентский кабинет плюс обработка заявки банком.

## Главное

- Полное техническое задание: **`docs/PROJECT_BRIEF.md`**. Читай его целиком перед началом работы и сверяйся с ним при любых сомнениях.
- Работай **по этапам** из раздела 13 брифа. Не переходи к следующему этапу, пока текущий не работает.
- После каждого этапа: запусти проект через `docker compose up --build`, проверь результат, сделай осмысленный коммит (`feat:`, `docs:`, `test:`, `chore:`) и допиши `docs/DEV_LOG.md`.
- Документы в `docs/` уже существуют как проектные черновики. Не перезаписывай их с нуля, а сверяй с реализацией и исправляй расхождения (этапы 8–9).
- Диаграммы в `docs/DIAGRAMS.md` — эталон процесса и состояний. Реализация должна им соответствовать; при расхождении обнови диаграмму и отметь в `DEV_LOG.md`.

## Стек

Java 21, Spring Boot 3.x (Maven Wrapper), PostgreSQL 16, Flyway, React 18 + TypeScript + Vite, Docker Compose. Версии фиксируем (lock-файлы, точные теги образов).

## Жёсткие правила

- Все данные **синтетические**. Реальных людей, компаний, ИНН и счетов нет.
- Внешние системы только **локальные моки** за интерфейсами. Никаких платных API, CDN, внешних шрифтов и сетевых вызовов во время работы приложения.
- Весь основной сценарий **внутри продукта**: без почты, SMS и мессенджеров.
- LLM и ML не нужны в основном пути. Если добавляешь ИИ-блок, то только по разделу 12 брифа (открытые веса, OpenAI-совместимый API, по умолчанию выключен).
- Секреты не коммитим. Конфигурация через переменные окружения, образец в `.env.example`.
- Не используй и не цитируй внутренние документы работодателей членов команды, названия реальных банков-клиентов и закрытых систем.
- Делай минимально необходимое для критериев кейса, не усложняй. Каждое упрощение сразу записывай в `docs/ASSUMPTIONS.md`.

## Язык

Код и идентификаторы на английском. Тексты интерфейса и документация на русском. Комментарии только там, где логика неочевидна.
