# Журнал разработки

Журнал ведётся по этапам. После каждого этапа записываем: что сделано, как проверить, что отклонилось от плана. Любое упрощение дублируем в `ASSUMPTIONS.md`.

## Формат записи

```
## Этап N. Название — дата
Сделано: ...
Как проверить: ...
Отклонения от плана: ...
Коммит / тег: ...
```
