# Портреты пользователей

Портреты построены по ответам респондентов (см. [`README.md`](README.md)). Для каждого клиентского портрета указана ближайшая демо-учётка прототипа, на которой можно проверить его сценарий.

## Общий портрет целевой аудитории

Представитель малого или микробизнеса, чаще всего индивидуальный предприниматель на упрощённой системе налогообложения, у которого нет финансового специалиста в штате. Деньги, закупки, поставщики и отчётность ведёт сам владелец или один человек рядом с ним, поэтому на оформление кредита у него остаётся мало времени.

| Признак | Что общего у респондентов |
|---|---|
| Задача кредита | оборотные деньги: закупка, кассовый разрыв до поступления выручки, реже оборудование и расширение |
| Сумма и срок | от 100 тыс. до 2 млн ₽, чаще 250–800 тыс. ₽ на 3–12 месяцев |
| Выручка | неравномерная: сезонность, праздники, задержки выплат от покупателей и площадок |
| С чего начинает | с банка, где открыт расчётный счёт, в расчёте, что банк уже знает обороты |
| Что важнее всего | понятная итоговая стоимость, скорость решения, минимум документов, всё онлайн |
| Чего боится | скрытых условий, неопределённости по срокам, отказа без объяснения, платежа, который не выдержит низкий сезон |
| Экспертиза | разная: от уверенного заёмщика до человека, который не может сам назвать сумму и срок |

Главное различие внутри аудитории: часть клиентов приходит с готовым запросом «столько-то на такой срок», а часть приходит с проблемой «не хватает денег, помогите понять, что делать». Прототип поддерживает оба входа: прямой подбор по цели, сумме и сроку и помощника, который начинает с вопросов о ситуации.

## Клиент 1. Продавец маркетплейса с сезонной выручкой

| | |
|---|---|
| Профиль | ИП на УСН, 1,5–2 года, продажи на маркетплейсе, сотрудников нет |
| Задача | закупка партии под сезон, логистика до склада площадки, сертификация, реклама; закрытие разрыва, пока площадка не выплатила выручку |
| Сумма и срок | 300–800 тыс. ₽ на 3–6 месяцев, на расширение ассортимента до 2 млн ₽ на 6–12 месяцев |
| Что важно | скорость и гибкость: «не успел закупиться к 8 Марта, потерял квартал»; досрочное погашение без штрафов; комфортный платёж не выше 20% среднемесячной выручки |
| Боли | банк не понимает, что выручка приходит выплатами площадки; сложно подтвердить доход; жёсткий график не совпадает с выплатами |
| Что убеждает | расчёт «закупил на 500 тыс., продал на 800 тыс., заплатил 50 тыс. процентов» и быстрое понятное решение |
| Ближайшая демо-учётка | `sokolov` (ИП, розничная торговля): встречное предложение при высокой нагрузке |

## Клиент 2. Опытный предприниматель в торговле

| | |
|---|---|
| Профиль | ИП, торговля, 4 года, бухгалтерия частично на аутсорсе, периодически берёт кредиты |
| Задача | пополнение оборотных средств, закупка партии, кассовый разрыв |
| Что важно | видеть до заявки сумму, ставку, платёж, переплату и требования; сравнивать варианты по сроку на одном экране |
| Боли | повторный ввод данных, которые банк уже знает; общие формулировки запросов «предоставьте документы о доходах»; статус «На рассмотрении» без деталей; переписка по разным каналам |
| Три изменения, которые он бы сделал | прозрачный статус со сроком и действиями; понятные условия и сравнение вариантов; одно место для документов и общения с банком |
| Ближайшая демо-учётка | `romashka`: автоодобрение и путь до выдачи без повторного ввода данных |

## Клиент 3. Владелица салона красоты с одной закупкой

| | |
|---|---|
| Профиль | ИП, салон маникюра, 3 мастера, сама работает мастером, бухгалтера нет |
| Задача | закупка проверенных расходных материалов на 2–3 месяца, около 250–300 тыс. ₽ |
| Что важно | «сколько беру, сколько возвращаю и сколько списывается каждый месяц»; решение заранее, потому что поставщик не держит цену долго |
| Боли | непонятна полная стоимость; нет уверенности в доступной сумме до заявки; неожиданные требования к документам; одобрение меньшей суммы ломает план закупки |
| Цитата | «Я владелица салона, а не банковский специалист» |
| Ближайшая демо-учётка | `orlova` (ИП, небольшой бизнес): овердрафт с лимитом от оборота. Со стороны банка этот профиль виден в очереди `uw1`: заявка салона красоты A-2026-000902 на 300 000 ₽ на 6 месяцев |

## Клиент 4. Начинающий предприниматель без опыта кредитования

| | |
|---|---|
| Профиль | ИП, кофейня «кофе с собой», 5 месяцев, один сотрудник |
| Задача | не сформулирована: денег не хватает на закупки, аренду и развитие, непонятно, нужен ли кредит |
| Сумма и срок | «может быть, 100 тысяч, может, 300»; срок не выбран |
| Что важно | помощник, который сначала задаёт простые вопросы о бизнесе, потом объясняет варианты на цифрах; несколько вариантов срока с платежом и переплатой; не подталкивать к кредиту |
| Боли | банк требует выбрать продукт, сумму и срок до того, как клиент к этому готов; термины «ставка от», «полная стоимость кредита» непонятны; неловко звонить с простыми вопросами |
| Ключевой вывод | клиент приходит не с запросом «300 000 ₽ на 12 месяцев», а с проблемой «не хватает денег» |
| Ближайшая демо-учётка | `kim` (ИП, общепит, 9 месяцев): сценарий помощника A1 и ручная проверка с запросом данных |

## Андеррайтер

Портрет построен по усреднённым ответам 8 андеррайтеров из разных банков.

| | |
|---|---|
| Задача по заявке | оценить благонадёжность заявителя, выявить финансовые и юридические риски и подготовить обоснованное заключение с рекомендацией |
| Что проверяет | данные заявителя и их корректность; срок работы бизнеса; финансовое состояние; задолженности; судебные дела и исполнительные производства; признаки банкротства; кредитную историю и долговую нагрузку |
| Сигналы повышенного внимания | задолженности от 50–100 тыс. ₽, суды, исполнительные производства, признаки банкротства, несоответствия в документах, нехватка сведений о компании, нестабильное финансовое состояние |
| Чего чаще всего не хватает | подтверждения доходов; уточняет по базам, документам и дополнительными запросами клиенту |
| Что помогает | структурированная сводка: данные заявителя, финансовые показатели, кредитная история, факторы риска, быстрый переход к первоисточнику |
| Где теряет время | поиск сведений в разных источниках, повторные проверки, уточнение расхождений, повторный ввод данных заявителя |
| Исходы кроме «да» и «нет» | запрос документов; одобрение на изменённых условиях: сумма, срок, ставка, залог, поручитель, созаёмщик |
| Что хочет видеть сразу | основные данные клиента, ключевые показатели риска, недостающие документы, историю изменений и комментарии предыдущих проверок |
| Принцип работы | «доверяй, но перепроверяй»: продолжает работу с места, где остановился коллега, по статусам и комментариям |
| Демо-учётки | `uw1`, `uw2` |
